# 리그 PC 비정상 종료 — 미팅용 요약 (2026-11-01 정리; 원문 [pc-stability.md](pc-stability.md))

## 증거 (Windows 시스템 로그, 최근 4개월)
- **비정상 종료 18회**(약 일주일에 한 번). 전부 `BugcheckCode = 0` → 블루스크린이 아니라 **전원이 끊기거나 하드웨어가 멈춘 뒤 다시 켜진 것**(덤프 없음).
- 꺼진 시각은 대부분 **밤~이른 아침, 아무도 안 쓰는 시간**(07:53, 00:15, 01:49, 06:03, 02:11, 04:03 …). 이 프로그램이 돌던 때와 겹친 적 없음.
- 절전 아님: 전원 계획 "고성능", 절전 진입 기록 0건.
- **WHEA 하드웨어 오류 1건**(11-01 00:15): "프로세서 코어, Internal parity error". CPU가 스스로 고친 오류로, **CPU 또는 메인보드 전원부(전압) 불안정**의 전조.

## 배제된 것
- 파워서플라이(새것으로 교체), 외부 전원(별도 전원 공급 장치, 다른 장비 정상), 절전, CMOS 배터리(시계·설정 유지용, 꺼짐 원인 아님), 이 프로그램.

## 남은 후보
1. **CPU / 메인보드 전원부** — 유휴 때 코어 전압이 가장 낮아 불안정이면 유휴 때 먼저 죽음. 보통 메인보드 교체로 귀결.
2. **메모리** — 비-ECC라 로그에 안 남고 멈춤/리셋으로 나타남. 검사·교체가 싸고 확실.

## 진단 순서 (1~3은 BIOS 화면 없이 가능)
1. memtest86 USB로 하룻밤 (부팅 메뉴 키만).
2. 메모리 두 개 이상이면 하나씩 빼고 일주일씩.
3. 보드 제조사 윈도우 유틸리티로 BIOS 기본값 복원(XMP/오버클럭 끔) + BIOS 업데이트.
4. 그래도 WHEA 오류 반복 → 메인보드(우선) 또는 CPU 교체. 같은 소켓이면 CPU·메모리·GPU는 그대로.

## 하트비트 로그 (이미 준비됨, 등록만 하면 됨)
- 10초마다 한 줄 기록, 7일 보관, 추적 성능에 영향 없음.
- 다음 꺼짐 때 **마지막 줄까지 10초 간격이면 전원부/보드(순간 꺼짐)**, **끊기기 전 간격이 벌어지면 메모리/멈춤** 쪽. 한두 번이면 방향이 잡힘.

## 하트비트가 잡은 첫 꺼짐 (11-01 23:58)
- 11-01 23:58:15~25에 꺼짐(이벤트 로그 마지막 생존 23:58:15, 하트비트 마지막 줄 23:58:25), 다음날 11:43 재부팅.
- 꺼지기 전 4시간 동안 10초 간격이 한 번도 안 벌어졌고 직전 1분 CPU 0.2~2 %, 여유 메모리 52 GB. **유휴 상태에서 순간 정지**, 멈춤·WHEA 기록 없음.
- 판독: 메모리/멈춤이 아니라 **메인보드·CPU 전원부(순간 전원 끊김)** 쪽. 같은 모양이 한 번 더 나오면 확정.

## 11-03에 두 번 더 꺼짐 (07:34, 20:14) — 한 번은 작업 중
- 07:34: 유휴(CPU 0.4 %), 10초 기록 끊김 없이 순간 정지. 11:25 재부팅.
- 20:14: 마지막 줄 CPU 72.7 % — 벤치(GUI 248 Hz)가 돌던 중. **유휴 때만 꺼지는 게 아님.** 모양은 같음(느려짐·WHEA 없음). 11-04 13:18 재부팅.
- 사흘에 네 번, 전부 순간 정지 → 보드/CPU 전원부. 보드 교체 결정(11-04).
